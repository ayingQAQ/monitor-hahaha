# monitor-hahaha

Monitor 手绘探针主题：纸张卡片、中英文手写字体、手绘控件与图表，以及轻微形变的 SVG 国旗。

![主题预览](preview.png)

## 安装

在 Monitor 的主题管理中使用 GitHub 仓库地址安装，或下载 [Releases](https://github.com/ayingQAQ/monitor-hahaha/releases/latest) 中的 `theme.tar.gz` 上传安装。主题短名为 `monitor-hahaha`。

支持站点公告与墨水颜色设置，访客可单独选择墨水颜色。

国旗包含提供素材中的 252 个国家和地区；缺失地区使用手绘地球与代码显示。

主题与第三方素材许可见 LICENSE、THIRD_PARTY.md 和 THIRD_PARTY_NOTICES.txt。
