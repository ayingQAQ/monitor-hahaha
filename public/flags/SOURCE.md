# Standard flag assets

Flags extracted from moxuun/monitor-theme-sketchprobe v0.1.4 release theme.tar.gz. Original country-flag-icons SVG files. The theme applies displacement and color treatment at runtime; those effects are not baked into these originals.

This theme preserves the original vector artwork and aspect ratio. A static low-frequency displacement filter, reduced saturation/opacity, and seeded Rough.js frame are applied around the artwork. No PNG flags or animated filters are used.
